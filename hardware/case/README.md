# Case do Polpad

Case impressa em duas partes para a placa do macropad (ESP32-C3
SuperMini, 18 switches e OLED 0,96").

| Arquivo | O que é |
|---|---|
| `case_top.stl` | Tampa superior (moldura das teclas e janela do display) |
| `case_bottom.stl` | Bandeja inferior |
| `gcode-ender3-v3-se/` | G-code pronto para a Creality Ender-3 V3 SE (Cura 5.12, camada de 0,12 mm) |

Para outra impressora, fatie os `.stl` no seu fatiador. O G-code só
serve para a Ender-3 V3 SE com o perfil em que foi gerado.
